# GENESIS + FORGE Constitution

## Mission
GENESIS is the dream product. FORGE is the engineering system that makes GENESIS possible without repeating prototype collapse.

## Truth ladder
IDEA -> RESEARCHED -> SPECIFIED -> IMPLEMENTED -> COMPILED -> RUNS -> TESTED -> VALIDATED -> DEVICE VERIFIED -> REGRESSION VERIFIED -> RECOVERABLE -> PRODUCT.

Never collapse these states.

## Permanent rules
1. **Do not fake progress.** A file write is not a build. A build is not a verified product.
2. **Build FORGE before the giant universe.** Automate environment check -> build -> run -> capture -> test -> compare -> checkpoint -> report.
3. **Stable vs Lab.** Stable remains usable; experiments happen in isolated Lab work until promotion gates pass.
4. **Tiny verified increments.** One bounded capability, evidence, checkpoint, then next capability.
5. **No giant rewrite debugging.** Capture -> reproduce -> isolate -> smallest justified repair -> regression test.
6. **Project Brain is canonical.** No critical project fact exists only in ChatGPT memory.
7. **Tyler is not CI.** Normal workflows capture logs, errors and evidence automatically.
8. **ChatGPT is not the source of truth.** ChatGPT proposes; FORGE evidence verifies.
9. **Prototypes are laboratories.** Successful experiments are either discarded or productized through architecture, integration, persistence, UX, diagnostics, performance, tests, recovery and verified artifacts.
10. **Offline survival.** Already-built GENESIS functionality and deterministic FORGE workflows must not depend on ChatGPT, a subscription or network access.
11. **Free required path.** No required paid tool, proprietary AI service or subscription dependency.
12. **Simulation truth is separate from rendering.** Pretty visuals cannot substitute for simulation state.
13. **Maximum causal depth per compute.** Use honest multiscale models rather than fake supercomputer claims.
14. **Every serious failure becomes cheaper next time.** Preserve reproduction, root cause, repair and regression evidence.
15. **Every fifth verified functional increment is a polish/stability gate.**

## Immediate build order
1. Persistent FORGE graph and Project Brain.
2. Real deterministic execution node.
3. Structured evidence artifact.
4. Real test node with PASS/FAIL derived from evidence.
5. Checkpoint/rollback.
6. Failure capture/replay.
7. Benchmark node.
8. Science model card + validation node.
9. First genuine GENESIS Foundation vertical slice.

## Anti-prototype rule
Do not make the biggest prototype we have ever made. Make the first product we can keep. Then make it deeper, stranger, larger and more beautiful while preserving every verified step underneath it.
