# PennySpawn retirement notice

PennySpawn is retired. The public `pennyspawn-ai/` route is a migration page that cleans up the former browser app and redirects visitors to Sandbox God Genic.

## No active commercial setup

The retired route does not include or support:

- advertising or ad-view rewards;
- invoices or payment requests;
- Bitcoin or Base USDC receiving-address configuration;
- wallet balance telemetry;
- local-model downloads or agent execution;
- user accounts, credential storage, custody, signing, or transactions.

Do not add seed phrases, recovery phrases, private keys, exchange credentials, wallet-signing authority, or private financial data to this repository.

Historical deployment and monetization instructions no longer apply. In particular, `monetization-config.js`, `ads.txt`, the old Settings screen, and the former PennySpawn service worker are not part of the public route.

Any future commercial application should be designed and reviewed as a separate project on an appropriate host, with truthful claims, explicit user consent, provider-policy compliance, and non-custodial boundaries. Do not restore earning claims, incentivized advertising, automated outreach, fake traffic, or automatic financial transactions to this redirect shell.
